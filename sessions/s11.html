Session 11 · Educational Data Mining & Adaptive Learning Analytics

เหมืองข้อมูลทางการศึกษาและการวิเคราะห์ร่องรอยการเรียนรู้

ทุกคลิกของผู้เรียนคือ ร่องรอยดิจิทัล ระบบแปลงมันเป็นตัวชี้วัด ทำนาย แล้วปรับบทเรียนเองแบบเรียลไทม์ แต่ต้อง ระวังสถิติหลอก และห้ามตราหน้าผู้เรียน

1 · Digital Traces สไลด์ 2–4

จาก Static CAI สู่ Adaptive Platform

Static CAI

ทุกคนเรียนลำดับเดียว หน้า 1 → 2 → 3 ตอบผิดก็แค่บอก “ผิด” แล้วให้ทำซ้ำแบบเดิม

Adaptive Platform

วัดความถูกต้องและความเร็วแบบเรียลไทม์ แล้วปรับเนื้อหาแบบพลวัต (Dynamic Branching) เข้าใจสูงข้ามไปโจทย์ท้าทาย ติดขัดได้โจทย์พื้นฐานทันที

ข้อมูลกิจกรรม 1 รายการ

พฤติกรรมสำคัญ 4 อย่างที่บันทึก

  • Response Latency วินาทีที่คิดก่อนกดส่ง
  • Content Revisit ย้อนดูวิดีโอหรือเนื้อหา
  • Hint Request จำนวนและระดับคำใบ้ที่ขอ
  • Item Accuracy ถูกหรือผิดรายข้อ

ข้อมูล 2 รูปแบบ

Numerical Logs เวลาต่อข้อ จำนวนครั้งทำซ้ำ % ถูก → ป้อนอัลกอริทึม ปรับความยากข้อถัดไปทันที

Text Logs ข้อความที่พิมพ์ในแชต → ส่งเข้า NLP วิเคราะห์แนวคิดที่เข้าใจผิด

2 · EDM vs Learning Analytics สไลด์ 5–7

EDM คือสมองหลังบ้าน LA คือคนขับหน้าบ้าน

EDM · Educational Data Mining

ระบบหลังบ้าน วิเคราะห์สถิติ หาแบบแผนการคลิก คำนวณโอกาสสอบตก

เปรียบ: เซ็นเซอร์และสมองกลที่วัดความเร็วรถ

LA · Learning Analytics

ระบบหน้าบ้าน เอาผลจาก EDM มาตัดสินใจแสดงผล เช่น ส่งข้อความกระตุ้น สับรางข้อสอบ

เปรียบ: ระบบขับอัตโนมัติที่สั่งเร่งหรือเบรกตามสภาพถนน

วงจรประมวลผลอัตโนมัติ

Automated Remediation Loop · แก้ปัญหาคิดไม่ออกอัตโนมัติ สัญญาณ: ทำโจทย์เรื่องเดิม ผิดติดกัน 3 ครั้ง และเวลาต่อข้อเพิ่มผิดปกติ → วินิจฉัย Impasse State ตอบสนอง: ระงับโจทย์ปัจจุบัน → ดึง โจทย์ปูพื้นฐาน (Prerequisite Concept) มาให้ทำ → ผ่านแล้วพากลับโจทย์เดิม
3 · Prediction & Clustering สไลด์ 8–11

ทำนายความเสี่ยง ประเมินความสามารถ และจัดกลุ่ม

Drop-out Prediction

ตัวแปรพยากรณ์

  • Skip Rate สูงขึ้น
  • เวลาใช้งานต่อวันลดลงต่อเนื่อง
  • ตอบผิดติดกันบ่อย

คำนวณ Churn/Drop-out Score เพื่อเตรียมมาตรการดึงดูดก่อนผู้เรียนเลิกใช้

Mastery Classification

แยกสถานะ ยังไม่เข้าใจ / กำลังพัฒนา / บรรลุเป้าหมาย ใช้ปลดล็อกด่านถัดไป หรือล็อกให้ฝึกซ้ำ

Proficiency Estimation

คำนวณคะแนนทักษะสะสม เช่น Elo Rating หรือ Item Response Theory เพื่อเลือกโจทย์ที่ยากพอดีกับระดับตอนนี้

Learner Clustering · จัดกลุ่มโดยไม่ต้องตั้งเกณฑ์ล่วงหน้า

กลุ่มลักษณะระบบปรับให้
Fast Learnersเวลาน้อย ถูกเกือบหมดข้ามโจทย์พื้นฐาน
Struggling Learnersใช้เวลานาน ทำซ้ำบ่อย แต่ผิดส่งคำใบ้และวิดีโอสั้น
Trial-and-Error Guessersตอบเร็วมาก ผิดเยอะหน่วงเวลาล็อกปุ่มตอบ
Bite-sized Usersใช้วันละ 3–5 นาทีสม่ำเสมอจัดคอนเทนต์กระชับ
4 · Preparing Data สไลด์ 12–15

แปลงคลิกเป็นความรู้ และทำความสะอาดข้อมูล

Feature Engineering

บันทึกการกดปุ่มอย่างเดียว บอกระดับความเข้าใจไม่ได้ ต้องแปลงเป็นตัวแปร

ข้อมูลดิบตัวแปรที่ได้
การคลิกตอบResponse_Time เวลาที่ใช้คิดต่อข้อ
การกดตรวจคำตอบFirst_Attempt_Success ถูกตั้งแต่ครั้งแรกไหม
ประวัติการใช้ปุ่มตัวช่วยHint_Abuse_Index ดัชนีกดคำใบ้ซ้ำ ๆ

Gaming the System Detection

Rapid Guessing กดสุ่มภายใน 1 วินาที → ตอบเร็วกว่าเวลาอ่านโจทย์ขั้นต่ำ ให้คะแนนข้อนั้นเป็นโมฆะ

Hint Abuse กดคำใบ้จนถึงระดับสุดท้ายเพื่อเอาคำตอบ → ซ่อนคำตอบสุดท้าย เปลี่ยนเป็นคำถามนำแบบ Socratic

Data Cleaning

  • Noise แอปกระตุกส่งคำตอบซ้ำ → รวมเป็นครั้งเดียว
  • Outlier เปิดแอปค้าง 2 ชั่วโมง → ตัดเวลาที่เกิน 5 นาทีออก
  • Session Dropout สัญญาณหลุด → พักสถานะไว้ ไม่บันทึกเป็นศูนย์
Cross-Validation · ตรวจความสอดคล้องหลายกิจกรรม เทียบผล Multiple Choice, Fill-in-the-blank และ Drag & Drop ถ้า เลือกตอบได้เต็ม แต่เติมคำไม่ได้เลย ประเมินว่าเดาสุ่ม และลดระดับความชำนาญลง

  • Hint Utility Rate คำใบ้ไหนดูแล้วยังผิด → คำใบ้ไม่ชัด
6 · Adaptive Logic สไลด์ 20–23

ตรรกะปรับเนื้อหา คำใบ้ 3 ขั้น และกลไกความปลอดภัย

Adaptive Branching Logic · ลองเลื่อนคะแนน

72%

Fast-Track

≥ 80% และตอบเร็ว → ข้ามพื้นฐาน ไปภารกิจท้าทาย

Standard Flow

50–79% → เส้นทางปกติ

Remedial Loop

< 50% หรือผิดซ้ำ → ซ่อมเสริมและย่อยเนื้อหา

Circuit Breakers · กลไกความปลอดภัย
