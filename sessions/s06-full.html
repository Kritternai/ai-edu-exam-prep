    สไลด์ 2

    เปรียบเทียบ 2 กระบวนทัศน์

    เข้าใจง่าย ๆยุคเก่าเหมือนเขียนสูตรอาหารให้คอมทำตาม ยุคใหม่เหมือนให้คอมชิมอาหารหลายจานพร้อมบอกว่าจานไหนอร่อย แล้วให้มันหาสูตรเอง

    คำว่า “กระบวนทัศน์” (Paradigm) หมายถึงกรอบความคิดพื้นฐานที่ใช้มองและแก้ปัญหา สไลด์นี้ใช้สมการคณิตศาสตร์ธรรมดา f(x) = y เป็นตัวเปรียบเทียบ: เราป้อนค่า x เข้าไปในฟังก์ชัน f แล้วได้ค่า y ออกมา โปรแกรมคอมพิวเตอร์ทุกโปรแกรมทำงานแบบนี้ คือรับข้อมูลเข้า แปลงด้วยกฎบางอย่าง แล้วให้ผลลัพธ์ออกมา

    โลกยุคเก่า (Rule-based Programming) คือ Input (x) + Human Rules (f) → Output (y) มนุษย์เป็นคนคิดกฎ f ด้วยสมองตัวเอง แล้วเขียนเป็นโค้ด เช่น “ถ้าคะแนนต่ำกว่า 50 ให้ถือว่าตก” คอมพิวเตอร์ทำตามกฎนั้นเป๊ะ ๆ ไม่ได้คิดเอง

    โลกยุคใหม่ (Machine Learning Paradigm) คือ Data (x) + Desired Output (y) → Learned Model (f) เราไม่ได้เขียนกฎเอง แต่ให้ตัวอย่างข้อมูลพร้อมคำตอบที่ต้องการ แล้วคอมพิวเตอร์ใช้สถิติ สร้างกฎ f ขึ้นมาเองโดยอัตโนมัติ สิ่งที่ได้ออกมาจากการเรียนรู้จึงไม่ใช่คำตอบ แต่เป็น “โมเดล” ที่นำไปตอบข้อมูลใหม่ได้

    จุดออกสอบ ถ้าโจทย์ถามว่า ML “สร้างอะไร” คำตอบคือ f (กฎหรือโมเดล) ไม่ใช่ x หรือ y

    สไลด์ 3

    ข้อจำกัดของ Rule-based

    เข้าใจง่าย ๆเหมือนเขียนป้าย “ห้ามทำ...” ติดผนังไปเรื่อย ๆ ทุกครั้งที่มีคนหาช่องโหว่ใหม่ สุดท้ายผนังเต็ม ป้ายขัดกันเอง และก็ยังมีช่องโหว่

    Rule-based ใช้ได้ดีกับปัญหาที่กฎชัดเจนและนับได้ แต่ปัญหาในโลกจริงจำนวนมากซับซ้อนเกินกว่าที่มนุษย์จะเขียนกฎได้หมด สไลด์ระบุปัญหาหลัก 2 ข้อ

    • ภาวะกฎระเบิด (Rule Explosion) ยิ่งปัญหายุ่งยาก ต้องเพิ่มกฎมากขึ้นเรื่อย ๆ กฎใหม่ไปทับซ้อนหรือขัดกับกฎเก่า จนสุดท้ายไม่มีใครดูแลระบบได้
    • ข้อยกเว้นไม่รู้จบ (Endless Edge Cases) มนุษย์คาดเดาเงื่อนไขทุกแบบในโลกจริงไม่ได้ครบ จะมีกรณีแปลก ๆ ที่กฎไม่ครอบคลุมเสมอ

    ตัวอย่างงานที่ Rule-based ทำได้แย่ คือ การคัดกรองอีเมลสแปม (คนส่งสแปมเปลี่ยนวิธีเขียนตลอด), การจดจำลายมือเขียน (แต่ละคนเขียนไม่เหมือนกัน) และ การประเมินพฤติกรรมมนุษย์ (มีปัจจัยมากและไม่ตายตัว)

    สไลด์ 4

    ตัวอย่างการเปลี่ยนจาก Rule-based ไป Data-driven

    สไลด์นี้ยกตัวอย่าง 3 กรณีให้เห็นว่ากฎที่คนเขียนพังตรงไหน และแนวทางที่ขับเคลื่อนด้วยข้อมูล (Data-driven) แก้ได้อย่างไร

    1. สแปมอีเมล กฎ “ถ้าเจอคำว่า ฟรี ให้ถือเป็นสแปม” ถูกหลบได้ง่าย ๆ ด้วยการพิมพ์ “ฟ.รี” ส่วนแนวทาง Data-driven ใช้ Naive Bayes ซึ่งคำนวณความน่าจะเป็นจากกลุ่มคำทั้งฉบับ ไม่ได้ยึดคำเดียว เมื่อเห็นคำหลายคำที่มักอยู่ในสแปม ความน่าจะเป็นรวมก็สูงขึ้นเอง

    2. เด็กกลุ่มเสี่ยง Dropout กฎ “ขาดเรียนเกิน 3 ครั้ง AND คะแนนควิซต่ำกว่า 50% ถือว่าเสี่ยง” แข็งกระด้าง เด็กที่ขาด 3 ครั้งพอดีแต่ควิซ 10% จะไม่ถูกจับ ส่วนแนวทาง Data-driven ลากเส้นแบ่ง (Decision Boundary) ในพื้นที่ข้อมูลพฤติกรรมหลายมิติ ซึ่งยืดหยุ่นกว่าเส้นตรงตายตัวที่คนกำหนด

    3. ภาพถ่ายลายมือ กฎ “เลข 8 ต้องมีวงกลมซ้อนกัน 2 วง” พังทันทีที่คนเขียนเบี้ยว ส่วนแนวทาง Data-driven มองภาพเป็นตัวเลขความสว่างของพิกเซล 784 พิกเซล (ภาพขนาด 28×28) แล้วปรับค่าน้ำหนัก (Weights) ทางคณิตศาสตร์จากตัวอย่างจำนวนมาก

    สไลด์ 5

    กระบวนทัศน์หลักของการเรียนรู้ของเครื่อง

    เข้าใจง่าย ๆครูมีเฉลยให้ = Supervised · ไม่มีเฉลย ให้หาเอง = Unsupervised · ไม่มีเฉลย แต่ได้คะแนนบวกลบหลังทำ = Reinforcement

    การเรียนรู้ของเครื่องแบ่งเป็น 3 กระบวนทัศน์หลัก ตัวแบ่งคือ “ข้อมูลที่ใช้สอนมีหน้าตาอย่างไร”

    • การเรียนรู้แบบมีผู้สอน (Supervised Learning) มีข้อมูลเข้า x และมีเฉลย y คู่กัน
    • การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning) มีแค่ข้อมูลเข้า x ไม่มีเฉลย
    • การเรียนรู้แบบเสริมแรง (Reinforcement Learning) ไม่มีเฉลยตรง ๆ แต่เรียนรู้ผ่านการลองผิดลองถูก (Trial & Error) และได้รางวัล (Reward) เป็นสัญญาณบอกว่าทำดีหรือไม่

    วิธีจำ ถามตัวเอง 2 ข้อ: มีรางวัลไหม ถ้ามีคือ Reinforcement ถ้าไม่มี ให้ถามต่อว่ามีเฉลยไหม ถ้ามีคือ Supervised ไม่มีคือ Unsupervised

    สไลด์ 6

    การเรียนรู้จากตัวอย่างที่มีเฉลย (Supervised Learning)

    เข้าใจง่าย ๆเหมือนทำแบบฝึกหัดแล้วเปิดเฉลยท้ายเล่มตรวจ ทำผิดตรงไหนก็แก้ความเข้าใจตรงนั้น

    นิยาม ป้อนชุดข้อมูลเป็นคู่อันดับ (xᵢ, yᵢ) เพื่อฝึกให้โมเดลหาฟังก์ชัน f ที่ทำให้ f(x) = y ได้แม่นที่สุด สไลด์เปรียบเหมือนนักเรียนทำแบบฝึกหัดที่มีเฉลยท้ายเล่ม ทำเสร็จก็เปิดเฉลยตรวจ แล้วแก้ความเข้าใจตามที่ผิด

    งานหลักของ Supervised Learning มี 2 แบบ ต่างกันที่ ชนิดของเฉลย y

    • การจำแนกประเภท (Classification) เฉลยเป็นกลุ่มหรือหมวดหมู่ เช่น ผ่าน/ตก, มะเร็ง/ปกติ, สแปม/ไม่สแปม
    • การถดถอย (Regression) เฉลยเป็นตัวเลขต่อเนื่อง เช่น ราคาบ้าน, คะแนนสอบ

    จุดออกสอบ โจทย์มักให้สถานการณ์แล้วถามว่าเป็นงานแบบไหน ให้ดูที่คำตอบที่ต้องการ ถ้าเป็นตัวเลขที่มีค่าได้หลายระดับคือ Regression ถ้าเป็นป้ายชื่อกลุ่มคือ Classification

    สไลด์ 7

    ตัวอย่างของ Supervised Learning

    Classification 2 มิติ เครื่องคัดแยกแอปเปิลกับส้ม ใช้ข้อมูล x = [น้ำหนัก, ความขรุขระ] ผลไม้แต่ละลูกกลายเป็นจุดบนกราฟ 2 แกน โมเดลเรียนรู้ที่จะลากเส้น Decision Boundary แบ่งจุดสองกลุ่มออกจากกัน ผลไม้ลูกใหม่ตกฝั่งไหนก็ทายว่าเป็นชนิดนั้น

    Regression หลายตัวแปร ประเมินราคาอสังหาริมทรัพย์จาก x = [พื้นที่, ห้องนอน, ระยะรถไฟฟ้า, อายุบ้าน] เมื่อมีตัวแปรหลายตัว โมเดลไม่ได้สร้างเส้นตรงเส้นเดียว แต่สร้างสมการ Hyperplane (ระนาบในหลายมิติ) ที่ใกล้จุดข้อมูลทั้งหมดที่สุด

    High-dimensional Classification วินิจฉัยภาพเซลล์มะเร็งเต้านมจากคุณลักษณะของเซลล์ 30 ตัวแปร มนุษย์มองพื้นที่ 30 มิติไม่ออก แต่โมเดลคำนวณได้ สไลด์ใช้คำว่า “บิดพับมิติข้อมูล” เพื่อหาเส้นแบ่งโซนเซลล์ปกติกับเซลล์มะเร็ง

    สไลด์ 8

    ตรรกะภายใน Supervised Learning (Linear Regression)

    เข้าใจง่าย ๆเหมือนหมุนปุ่มวิทยุหาคลื่น ฟังว่าเพี้ยนไปทางไหน (error) แล้วหมุนกลับทางนั้นทีละนิด (learning rate) จนเสียงชัด

    โจทย์คือทำนายคะแนนสอบ y จากชั่วโมงอ่านหนังสือ x ด้วยสมการ y = w * x โดย w (weight) คือตัวคูณที่โมเดลต้องหาเอง ข้อมูลคือ (1,20), (2,40), (3,60), (4,80), (5,100) ซึ่งคำตอบที่ถูกคือ w = 20

    data = [(1, 20), (2, 40), (3, 60), (4, 80), (5, 100)]
w = 0.0 ; learning_rate = 0.01

for epoch in range(100):
  for x, y_true in data:
      y_pred = w * x                         # 1. ทำนาย
      error = y_pred - y_true                # 2. หา Error
      w = w - (learning_rate * error * x)    # 3. ปรับ Weight w
    • เริ่มต้น w = 0 โมเดลยังไม่รู้อะไร ทายทุกข้อเป็น 0
    • ขั้น 1 ทำนาย คำนวณ y_pred = w * x
    • ขั้น 2 หา Error เทียบกับเฉลย error = y_pred − y_true ถ้าทายต่ำกว่าเฉลย error จะติดลบ
    • ขั้น 3 ปรับ Weight w = w − learning_rate × error × x ถ้า error ติดลบ การลบค่าติดลบจะทำให้ w เพิ่มขึ้น ทายครั้งหน้าจึงใกล้เฉลยขึ้น ตัวคูณ x ทำให้ข้อที่ x ใหญ่มีผลต่อการปรับมากกว่า
    • วนซ้ำ ครบข้อมูล 1 รอบเรียกว่า 1 epoch ทำ 100 epoch แล้ว w จะเข้าใกล้ 20

    learning_rate คือขนาดก้าวในการปรับ ถ้าเล็กไปเรียนช้า ถ้าใหญ่ไปจะเลยเป้าและแกว่ง ในใบงานใช้รูปแบบ error = target − prediction และ weight = weight + error × learning_rate ซึ่งความหมายเหมือนกัน แค่กลับเครื่องหมาย

    ลองคิด x = 3, target = 15, weight = 2, learning_rate = 0.1 → ทาย 6, error = 9, weight ใหม่ = 2 + 0.9 = 2.9

    สไลด์ 9

    การเรียนรู้จากตัวอย่างที่ไม่มีเฉลย (Unsupervised Learning)

    เข้าใจง่าย ๆเหมือนเทเลโก้ปนกันทั้งกล่องให้เด็ก ไม่มีใครบอกวิธีแยก แต่เด็กจะจับกองตามสีหรือขนาดได้เอง

    นิยาม ป้อนเฉพาะข้อมูลดิบ x ไม่มีเฉลย y ให้ระบบค้นหารูปแบบหรือโครงสร้างที่ซ่อนอยู่เอง สไลด์เปรียบเหมือนเด็กจัดกล่องเลโก้ที่ไม่มีคู่มือ ไม่มีใครบอกว่าต้องแยกอย่างไร แต่เด็กจะคัดแยกตามสีหรือขนาดได้เองโดยสัญชาตญาณ

    งานหลักมี 2 แบบ

    • การจัดกลุ่ม (Clustering) คำนวณระยะห่างทางเรขาคณิต (Distance) ระหว่างจุดข้อมูล จุดที่อยู่ใกล้กันถูกจัดไว้กลุ่มเดียวกัน
    • การลดมิติข้อมูล (Dimensionality Reduction) ลดตัวแปรจำนวนมากให้เหลือเฉพาะตัวที่สำคัญ เครื่องมือที่ยกตัวอย่างคือ PCA

    PCA (Principal Component Analysis) เป็นเครื่องมือทางสถิติที่หา แกนอ้างอิงใหม่ (Principal Components) โดยพยายามรักษาความหลากหลาย (Variance) ของข้อมูลเดิมไว้ให้มากที่สุด แกนแรกคือทิศที่ข้อมูลกระจายมากที่สุด แกนถัดไปตั้งฉากกับแกนก่อน ถ้าเก็บไว้แค่ไม่กี่แกนแรก ก็ลดจำนวนตัวแปรได้มากโดยเสียข้อมูลสำคัญน้อย

    สไลด์ 10

    ตัวอย่าง Unsupervised Learning

    Customer Segmentation ห้างสรรพสินค้าอยากรู้ว่าลูกค้ามีกี่แบบ ใช้ข้อมูล x = [รายได้, คะแนนใช้จ่าย] ให้ K-Means แบ่งกลุ่มอัตโนมัติ เช่น รายได้สูงใช้จ่ายสูง หรือรายได้สูงแต่ใช้จ่ายน้อย ไม่ต้องมีใครกำหนดกลุ่มไว้ก่อน

    Association Rules หาแพทเทิร์นของสินค้าที่ถูกซื้อด้วยกัน กรณี Walmart ค้นพบความสัมพันธ์ที่ไม่มีใครคาดว่า ผ้าอ้อมเด็กมักถูกซื้อคู่กับเบียร์ ข้อมูลไม่มีเฉลย แต่ระบบนับความถี่การเกิดร่วมกันแล้วพบรูปแบบเอง ในใบงานใช้หลักเดียวกันกับห้องสมุด คนที่ยืม “คณิต” มักยืม “ฟิสิกส์” ด้วย จึงควรแนะนำฟิสิกส์

    Dimensionality Reduction ด้วย PCA หาปัจจัยแฝงของผู้เรียน เช่น บีบแบบสอบถามวัดความถนัด 100 ข้อ ให้เหลือ 3 แกนหลักโดยไม่สูญเสียสาระสำคัญ การลดมิติคือการตัดข้อมูลที่ซ้ำซ้อนหรือส่งผลน้อยออก เพื่อลดความซับซ้อนของชุดข้อมูล

    สไลด์ 11

    ตัวอย่างโปรแกรม Unsupervised Learning ใช้ K-Means

    เข้าใจง่าย ๆK-Means คือปักธงตัวแทนกลุ่มไว้ก่อน ให้ทุกคนเดินไปหาธงที่ใกล้ที่สุด แล้วย้ายธงไปไว้ตรงกลางกลุ่ม ทำซ้ำจนธงไม่ขยับ

    โจทย์คือจัดกลุ่มพฤติกรรมนักเรียน 6 คนจาก x = [เข้าเรียน, ส่งงาน] โดยคำนวณ Euclidean Distance (ระยะทางเส้นตรงระหว่างสองจุด)

    import math

students = [[1, 2], [2, 1], [1, 1], [8, 9], [9, 8], [9, 10]]
centroid_A, centroid_B = [1, 1], [9, 9]

group_A, group_B = [], []
for s in students:
  dist_A = math.sqrt((s[0]-centroid_A[0])**2 + (s[1]-centroid_A[1])**2)
  dist_B = math.sqrt((s[0]-centroid_B[0])**2 + (s[1]-centroid_B[1])**2)
  if dist_A < dist_B: group_A.append(s)
  else: group_B.append(s)

print(f"{group_A = }, {group_B = }")
    • centroid คือจุดตัวแทนของแต่ละกลุ่ม เริ่มที่ A = [1,1] และ B = [9,9]
    • สำหรับนักเรียนแต่ละคน คำนวณระยะไปหา A และ B ด้วยสูตร √((x₁−x₂)² + (y₁−y₂)²)
    • อยู่ใกล้ตัวแทนไหนก็เข้ากลุ่มนั้น ผลคือ A = [1,2], [2,1], [1,1] และ B = [8,9], [9,8], [9,10]
    • ตัวอย่าง [2,1] ห่าง A = √(1² + 0²) = 1 และห่าง B = √(7² + 8²) = √113 ≈ 10.63 จึงเข้ากลุ่ม A

    K-Means ฉบับเต็มจะทำซ้ำอีกขั้น คือ ย้าย centroid ไปที่ค่าเฉลี่ยของสมาชิกในกลุ่ม แล้วจัดกลุ่มใหม่ วนจนตัวแทนไม่ขยับ ในใบงาน คะแนน [10, 15, 80, 85] เริ่ม A = 20, B = 80 หลัง 1 รอบได้ A ใหม่ = 12.5 และ B ใหม่ = 82.5

    สไลด์ 12

    การเรียนรู้ผ่านการลองผิดลองถูก (Reinforcement Learning)

    เข้าใจง่าย ๆเหมือนฝึกสุนัข ไม่มีใครอธิบายให้มันฟัง แต่ทำแล้วได้ขนมหรือโดนดุ มันจะค่อย ๆ รู้เองว่าควรทำอะไร

    นิยาม สมองกล (Agent) เรียนรู้อยู่ในสภาวะแวดล้อม (Environment) และเลือกการกระทำ (Action) เพื่อให้ได้ รางวัลสะสมรวมสูงสุด (Maximize Cumulative Reward) คำว่า “สะสม” สำคัญมาก หมายความว่ามองระยะยาว บางครั้งยอมเสียรางวัลตอนนี้เพื่อได้มากกว่าในอนาคต

    สไลด์เปรียบเหมือนการฝึกสุนัข หรือการเล่นเกมเพื่อชนะ ไม่มีใครบอกคำตอบที่ถูกล่วงหน้า แต่ทำแล้วได้รางวัลหรือโดนลงโทษ แล้วค่อย ๆ ปรับพฤติกรรม

    วงจร 4 องค์ประกอบหลัก

    • Agent ส่ง Action (A) ไปยัง Environment
    • Environment ตอบกลับด้วย State (S) ใหม่ และ Reward (R)

    วงจรนี้วนซ้ำไปเรื่อย ๆ Agent เรียนรู้ว่าใน State แบบไหน ควรเลือก Action อะไรถึงจะได้รางวัลรวมสูง

    สไลด์ 13

    องค์ประกอบหลัก: Agent และ Environment

    Agent (สมองกล/ตัวดำเนินกิจกรรม) มีหน้าที่ทำความเข้าใจสถานะ (State) แล้วตัดสินใจเลือกทำบางอย่าง (Action) เพื่อเป้าหมายระยะยาว ในเกมคือตัวละคร ในการศึกษาคือ ระบบแนะนำบทเรียน AI (Adaptive Learning System)

    Environment (สิ่งแวดล้อม) มีหน้าที่ตอบสนองต่อการกระทำของ Agent ส่งข้อมูลกลับมาว่าโลกเปลี่ยนไปอย่างไร (New State) และให้รางวัลหรือบทลงโทษ (Reward) ในเกมคือด่าน ในการศึกษาคือ ตัวผู้เรียน ไม่ว่าจะเป็นนักเรียนจริงหรือแบบจำลองตัวตนนักเรียน

    จุดออกสอบ หลายคนสลับกัน: ระบบ AI = Agent, นักเรียน = Environment

    สไลด์ 14

    องค์ประกอบหลัก (ต่อ): Action และ State

    Action (A · การกระทำ) คือสิ่งที่ Agent เลือกทำได้ ณ เวลานั้น ในเกมคือกดเดินหน้าหรือกระโดด ในระบบการศึกษาคือ การเลือกส่งโจทย์คณิตระดับยากหรือง่าย ไปให้นักเรียน

    State (S · สถานะ) คือข้อมูลปัจจุบันของสิ่งแวดล้อมที่ Agent ใช้ประกอบการตัดสินใจ ในเกมคือพิกัดและพลังชีวิตของตัวละคร ในระบบการศึกษาคือ ระดับความรู้ปัจจุบันและประวัติคะแนนล่าสุดของนักเรียน

    สไลด์ 15

    องค์ประกอบหลัก (ต่อ): Reward

    เข้าใจง่าย ๆReward คือ “คะแนนทันที” หลังทำแต่ละครั้ง ถ้าตั้งคะแนนผิด AI ก็จะขยันทำสิ่งผิด

    Reward (R · รางวัล) คือแต้มบวก (รางวัล) หรือแต้มลบ (บทลงโทษ) ที่ได้ ทันที หลังทำ Action เพื่อบอกว่าสิ่งที่ทำไปดีหรือแย่ ในเกมคือคะแนน ในระบบการศึกษา ถ้านักเรียนทำโจทย์ข้อนั้นผ่านก็บวกแต้ม ถ้านักเรียนกดออกจากระบบเพราะโจทย์ยากเกินไปก็ติดลบแต้ม

    สไลด์หมายเหตุว่า [Reward + New State] นับเป็น 1 องค์ประกอบ เพราะ Environment ส่งสองอย่างนี้กลับมาพร้อมกันในแต่ละรอบ จึงเป็นวงจร 4 องค์ประกอบคือ Agent, Environment, Action และ State+Reward

    การออกแบบ Reward สำคัญมาก ถ้าให้รางวัลผิด AI ก็เรียนพฤติกรรมผิด เช่น ในใบงานให้คิดว่าบอตเตือนส่งงานควรได้แต้มติดลบถ้าเตือนตอนนักเรียนกำลังเรียน และได้แต้มบวกถ้าเตือนหลังเลิกเรียน

    สไลด์ 16

    ตัวอย่างของ Reinforcement Learning

    สัญชาตญาณ: ฝึกสุนัขนั่ง นั่งได้ขนม (+1) เห่าโดนดุ (−1) สุนัขค่อย ๆ เรียนว่าการนั่งคุ้มกว่า

    หุ่นยนต์ในเขาวงกต (Grid World) เดินตกกับดักได้ −10 เดินเจอทางออกได้ +50 ผลที่ได้ถูกบันทึกลง Q-Table ซึ่งเป็นตารางความจำว่าในแต่ละช่อง แต่ละทิศให้คะแนนเท่าไร ในใบงาน ช่องเริ่มต้นมีตาราง [ซ้าย, ขวา] = [0, 0] เดินขวาแล้วได้ −5 ตารางจึงเป็น [0, −5] รอบหน้า AI จะเลือกซ้ายเพราะค่าสูงกว่า

    การทรงตัวทางฟิสิกส์ (CartPole) ขยับรถเข็นซ้ายขวาเพื่อเลี้ยงไม้ที่ตั้งอยู่ไม่ให้ล้ม ยิ่งไม้ตั้งได้นานยิ่งได้รางวัล เป็นหลักการเบื้องต้นของโดรนและหุ่นยนต์ทรงตัว

    สไลด์ 17

    ตัวอย่างของ Reinforcement Learning (ต่อ)

    การวางแผนระยะยาว (Super Mario) AI ยอมเสี่ยงกระโดดเหยียบศัตรู แม้อาจตาย เพื่อแลกกับคะแนนในด่านที่สูงกว่า แสดงว่ามันไม่ได้ดูแค่รางวัลตรงหน้า แต่ดูรางวัลสะสม

    ระดับสะเทือนโลก (AlphaGo ของ DeepMind) ใช้วิธี Self-play แข่งกับตัวเองนับล้านกระดาน จนค้นพบกลยุทธ์ที่มนุษย์ไม่คุ้นเคย คือ สละหมากเพื่อยึดพื้นที่ระยะยาว ซึ่งเป็นตัวอย่างชัดเจนของการยอมเสียตอนนี้เพื่อชนะในตอนท้าย

    ด้านครุศาสตร์ (Adaptive Learning Pathway) AI จัดข้อสอบตามความเข้าใจของนักเรียนแต่ละคน โดยเป้าหมายระยะยาวคือให้นักเรียนสอบผ่านปลายภาคได้สูงสุด ไม่ใช่แค่ทำข้อถัดไปให้ถูก

    สไลด์ 18

    ความสมดุล (Generalization)

    เข้าใจง่าย ๆนักเรียนที่ดีไม่ใช่คนที่จำข้อสอบเก่าได้หมด แต่คือคนที่เจอข้อสอบใหม่แล้วยังทำได้

    เป้าหมายสูงสุดของ Machine Learning ไม่ใช่การทำข้อสอบเก่า (Training Data) ได้ 100% แต่คือ Generalization หมายถึงความสามารถในการทำข้อสอบใหม่ที่ไม่เคยเห็น (Unseen Data) ได้ดี เพราะในการใช้งานจริง โมเดลต้องเจอข้อมูลใหม่ตลอด

    สภาวะอันตรายมี 2 อย่าง

    • Underfitting (เรียนรู้น้อยเกินไป · ขี้เกียจ) โมเดลเรียบง่ายเกินไป จับความสัมพันธ์อะไรไม่ได้เลย เรียกว่า High Bias คือมีอคติไปทางคำตอบง่าย ๆ
    • Overfitting (เรียนรู้ดีเกินไป · นักท่องจำ) โมเดลซับซ้อนเกินไป ท่องจำไปถึงสัญญาณรบกวน (Noise) เรียกว่า High Variance คือผลลัพธ์แกว่งตามข้อมูลฝึกทุกจุด

    Good Fit คือจุดสมดุลที่จับเฉพาะแก่นแท้ของข้อมูล (Signal) ยืดหยุ่นและแม่นยำ

    สไลด์ 19

    ตัวอย่างของ Overfitting และ Underfitting

    กรณีนักเรียนเตรียมสอบ Underfit คือไม่ยอมอ่านหนังสือ ตอบ ก. ทุกข้อ จึงตกทั้งข้อสอบซ้อมและสอบจริง ส่วน Overfit คือท่องจำโจทย์เก่าทั้งหมด แต่ย้ายข้างสมการไม่เป็น ข้อสอบซ้อมได้เต็ม แต่พอข้อสอบจริงเปลี่ยนตัวเลขก็ทำไม่ได้เลย

    กรณีจำแนกรูปสุนัข Underfit คือตั้งกฎหละหลวม เช่น “มี 4 ขาคือสุนัข” ผลคือทายแมว ม้า และโต๊ะเป็นสุนัขหมด ส่วน Overfit คือเจาะจงเกินไป “ต้องเป็นชิบะสีน้ำตาลใส่ปลอกคอแดงเท่านั้น” พอเจอพุดเดิ้ลสีขาวก็ทายว่าไม่ใช่สุนัข

    กรณีทำนายราคาบ้าน (Regression) Underfit คือลากเส้นตรงแนวนอนผ่ากลางกราฟ บอกว่าบ้านกี่ตารางวาก็ราคาเท่ากัน ส่วน Overfit คือลากเส้นคดเคี้ยววิ่งเข้าหาจุดข้อมูลทุกจุด รวมถึง “บ้านผีสิง” ที่ราคาตกผิดปกติ ซึ่งเป็น Noise ที่ไม่ควรจำ

    สไลด์ 20

    สรุปภาพรวม Overfitting และ Underfitting

    เข้าใจง่าย ๆUnderfit = อ่านน้อยไป · Overfit = ท่องจำจนติดรายละเอียดขยะ · Good Fit = เข้าใจหลักแล้วนำไปใช้ได้

    ถ้ามองเป็นเส้นกราฟบนข้อมูลชุดเดียวกัน จะเห็น 3 แบบ

    • Underfitting เส้นตรงทื่อ ๆ ไม่ครอบคลุมจุดข้อมูล · High Bias / Low Variance
    • Good Fit เส้นโค้งราบเรียบ จับแนวโน้มหลักได้อย่างยืดหยุ่น · Balanced
    • Overfitting เส้นคดเคี้ยวรุนแรง วิ่งผ่านทุกจุดข้อมูล · Low Bias / High Variance

    แนวทางแก้ไข

    • แก้ Underfit เพิ่มความซับซ้อนของโมเดล หรือเพิ่มจำนวนตัวแปร (Features) ให้โมเดลมีข้อมูลพอจะจับความสัมพันธ์
    • แก้ Overfit เพิ่มปริมาณข้อมูล ตัด Noise ทิ้ง หรือลดความซับซ้อนของโมเดล (Regularization)

    กับดัก วิธีแก้ของสองภาวะนี้ตรงข้ามกัน ข้อสอบชอบถามว่า “ข้อใดไม่ใช่วิธีแก้ Overfitting” แล้วใส่ “เพิ่มความซับซ้อนของโมเดล” เป็นตัวเลือก

    สไลด์ 21

    จริยธรรมและจิตวิทยาทางการศึกษา

    เข้าใจง่าย ๆAI บอกได้แค่ว่า “ในอดีต เด็กแบบนี้มักเป็นแบบนั้น” แต่ไม่รู้ว่าเด็กคนนี้กำลังเจออะไร ครูคือคนที่รู้

    หัวใจของสไลด์นี้คือ ความตระหนักรู้ของผู้สอน (Human-in-the-Loop) ครูต้องอยู่ในวงจรการตัดสินใจเสมอ เหตุผลมีดังนี้

    • AI คือเครื่องมือคำนวณทางสถิติ ไม่ใช่สามัญสำนึก มันหาแพทเทิร์นในตัวเลขได้ แต่ไม่เข้าใจบริบทชีวิตของนักเรียน
    • ระวัง Algorithmic Bias (อคติทางสถิติ) ถ้าข้อมูลในอดีตมีความไม่เป็นธรรม เช่น นักเรียนบางกลุ่มเคยได้รับโอกาสน้อย โมเดลจะเรียนและผลิตซ้ำอคตินั้น
    • หลีกเลี่ยง Self-fulfilling Prophecy (การทำนายที่เป็นจริงเอง) ถ้า AI ทำนายว่าเด็กคนหนึ่งจะสอบตก แล้วครูเชื่อจนลดความคาดหวังหรือเลิกให้โอกาส เด็กก็อาจตกจริงเพราะการกระทำของครู ไม่ใช่เพราะความสามารถ
    • อย่าให้ผลพยากรณ์ของ AI ไปตราหน้าหรือตัดโอกาสเด็ก

    ครูคือผู้ถือครองความเห็นอกเห็นใจ (Empathy) และเป็น ผู้ตัดสินใจขั้นสุดท้าย

    สไลด์ 22–23

    สรุป

    • Paradigm Shift จาก f(x) = y แบบที่คนเขียนกฎเอง สู่การสกัดกฎจากข้อมูล (Data-driven)
    • 3 Paradigms Supervised (มีเฉลย: Classification / Regression), Unsupervised (ไม่มีเฉลย: Clustering / Dimensionality Reduction) และ Reinforcement (ลองผิดลองถูก: Reward / Penalty / Policy)
    • ความสมดุล หลีกเลี่ยง Overfitting และ Underfitting เพื่อให้ได้โมเดลที่ใช้งานจริงได้ (Generalization)

    คำว่า Policy ในบรรทัด Reinforcement หมายถึง “กลยุทธ์” ที่ Agent ใช้เลือก Action ในแต่ละ State ซึ่งเป็นสิ่งที่ RL พยายามเรียนรู้ ส่วน Regression สไลด์ขยายความว่าเป็นการสอนคอมพิวเตอร์ให้พยากรณ์ตัวเลขต่อเนื่องจากข้อมูลในอดีต
