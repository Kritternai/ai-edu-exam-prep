โครงข่ายประสาทเทียมเบื้องต้น (Neural Networks)

สารบัญรายสไลด์
    สไลด์ 2

    ทำไมคอมพิวเตอร์ทั่วไปถึงไม่ฉลาดเท่ามนุษย์

    เข้าใจง่าย ๆคอมทั่วไปเหมือนพนักงานเก่งคนเดียวทำทีละงาน สมองเหมือนพนักงานธรรมดาเป็นพันล้านคนทำพร้อมกัน

    คอมพิวเตอร์ทั่วไปใช้สถาปัตยกรรมดั้งเดิมแบบ Von Neumann ซึ่งประมวลผลเชิงเส้น ทีละคำสั่ง (Sequential Processing) รับคำสั่งหนึ่ง ทำเสร็จ แล้วค่อยทำคำสั่งถัดไป วิธีนี้เก่งมากกับงานคณิตศาสตร์ที่มีขั้นตอนชัดเจน แต่ล้มเหลวในงานที่มนุษย์ทำได้แทบไม่ต้องคิด เช่น การรู้จำใบหน้า หรือการตีความภาษา เพราะงานพวกนี้ไม่มีขั้นตอนตายตัวให้เขียนเป็นคำสั่ง

    ทางออกคือ Artificial Neural Networks (โครงข่ายประสาทเทียม) ซึ่งหันมาศึกษาและเลียนแบบสมองมนุษย์ สมองทำงานแบบ ประมวลผลขนานมหาศาล (Massively Parallel Processing) ผ่านเซลล์ประสาทนับพันล้านตัวที่ทำงานพร้อมกัน แต่ละตัวทำงานง่าย ๆ แต่เมื่อต่อกันเป็นเครือข่ายก็ทำงานซับซ้อนได้

    สไลด์ 3

    โครงสร้างเซลล์ประสาทมนุษย์ (Biological Neuron)

    เซลล์ประสาท 1 ตัวมี 4 ส่วนที่ต้องรู้ เพราะแต่ละส่วนจะกลายเป็นส่วนประกอบของเซลล์ประสาทเทียมในสไลด์ถัดไป

    • Dendrites (เดนไดรต์) แขนรับสัญญาณไฟฟ้าเคมีจากเซลล์อื่น ทำหน้าที่เป็นทางเข้า (Input)
    • Soma (ตัวเซลล์) ศูนย์กลางที่รวมสัญญาณกระตุ้นทั้งหมดเข้าด้วยกัน (Summation)
    • Axon (แอกซอน) สายส่งสัญญาณที่ประมวลผลแล้วออกไป (Output Line)
    • Synapse (ไซแนปส์) รอยต่อระหว่างเซลล์ ทำหน้าที่ปรับความเข้มของสัญญาณ (Weights) และเป็น จุดที่เกิดการเรียนรู้ เมื่อเราเรียนรู้สิ่งใหม่ ความแข็งแรงของรอยต่อเหล่านี้จะเปลี่ยนไป
    สไลด์ 4

    ตรรกะการยิงสัญญาณของสมอง

    เข้าใจง่าย ๆเหมือนกริ่งประตู กดเบาไปไม่ดัง กดแรงพอก็ดังเต็มเสียง กดแรงกว่านั้นก็ไม่ได้ดังกว่าเดิม

    เซลล์ประสาทยิงสัญญาณตามกฎ ทำทั้งหมดหรือไม่ทำเลย (All-or-None Law) ไม่มีการยิงครึ่ง ๆ กลาง ๆ

    • ถ้าสัญญาณกระตุ้นรวม ไม่ถึง ค่าขีดเริ่มเปลี่ยน (Threshold) เซลล์จะไม่ยิงสัญญาณ ผลลัพธ์ = 0
    • ถ้าสัญญาณกระตุ้นรวม สูงเกิน ค่าขีดเริ่มเปลี่ยน เซลล์จะยิงสัญญาณเต็มที่ ผลลัพธ์ = 1

    หลักการนี้คือที่มาของ Step Function และแนวคิด “ตัดสินใจเมื่อผ่านเกณฑ์” ในเซลล์ประสาทเทียม

    สไลด์ 5

    การแปลงชีววิทยาไปเป็นเซลล์ประสาทเทียม (Perceptron Model)

    เข้าใจง่าย ๆPerceptron คือคนตัดสินใจ 1 คนที่ฟังความเห็นหลายคน (x) ให้น้ำหนักแต่ละคนไม่เท่ากัน (w) แล้วสรุปว่าจะทำหรือไม่

    Perceptron คือแบบจำลองเซลล์ประสาทเทียม 1 ตัว แต่ละส่วนของเซลล์จริงถูกแปลงเป็นสัญลักษณ์ทางคณิตศาสตร์ดังนี้

    • Dendrites → Inputs x₁, x₂, …, xₙ ตัวแปรนำเข้า
    • Synapse → Weights w₁, w₂, …, wₙ ค่าน้ำหนักประจำแต่ละเส้น
    • Threshold → Bias b ค่าชดเชยระดับการตัดสินใจ
    • Soma → Weighted Sum z ผลรวมแบบถ่วงน้ำหนัก
    • Action Potential → Activation Function f(z) ฟังก์ชันที่ตัดสินว่าจะส่งสัญญาณออกไปเท่าไร

    ภาพในสไลด์แสดงว่าข้อมูลแต่ละตัว x ถูกคูณด้วย w ของเส้นตัวเอง แล้วไปรวมกันที่ z ก่อนผ่าน f(z) เพื่อให้ได้คำตอบที่ทำนาย y_pred

    สไลด์ 6

    สมการรากฐานของเซลล์ประสาทเทียม

    เข้าใจง่าย ๆตัดสินใจว่าจะไปดูหนังไหม: เพื่อนชวน (x₁) สำคัญมาก (w สูง) ฝนตก (x₂) ทำให้ไม่อยากไป (w ติดลบ) ส่วน Bias คือนิสัยเดิมว่าชอบออกไปเที่ยวแค่ไหน

    ภายในโหนดประมวลผลเดี่ยว (Single Neuron) มีสมการเดียวที่ต้องจำให้ได้

    z = (x₁w₁ + x₂w₂ + … + xₙwₙ) + b
    • Weight (w) คือความสำคัญของข้อมูลแต่ละตัว ค่ามากแปลว่าข้อมูลนั้นมีผลมาก ค่าบวก = กระตุ้น ให้โหนดยิง ค่าลบ = ยับยั้ง
    • Bias (b) คือเกณฑ์ความตื่นตัวของโหนด บอกว่าโหนดนี้ตัดสินใจง่ายหรือยาก ถ้า b สูง แม้ข้อมูลเข้าน้อยก็ยิงได้ ถ้า b ต่ำ ต้องมีสัญญาณเข้ามามากถึงจะยิง

    ลองคิด x₁ = 1, x₂ = 0.5, w₁ = 0.6, w₂ = −0.4, b = 0.1 → z = 0.6 − 0.2 + 0.1 = 0.5

    สไลด์ 7

    ทำไมต้องมี Activation Function

    เข้าใจง่าย ๆไม้บรรทัดตรงกี่อันต่อกันก็ยังได้เส้นตรง Activation คือข้อต่อที่ทำให้งอได้ จึงวาดรูปโค้งได้

    ปัญหาขีดจำกัดของสมการเชิงเส้น (Linear Limitation) สมการ z = Σwx + b เป็นสมการเส้นตรง ถ้าไม่ใช้ฟังก์ชันกระตุ้น การนำเส้นตรงมาต่อกันกี่ชั้นก็ยังได้เส้นตรง โครงข่ายที่ต่อกัน 100 ชั้นจะยุบสมการรวมแล้วเท่ากับชั้นเดียว คำนวณได้แค่เส้นตรงเท่านั้น การมีหลายชั้นจึงไม่มีประโยชน์

    ปัญหา XOR (Exclusive OR) เป็นตัวอย่างคลาสสิกของข้อมูลที่ใช้เส้นตรงเส้นเดียวขีดแบ่งกลุ่มไม่ได้ (Non-linearly Separable) ปัญหาในโลกจริงส่วนมากซับซ้อนแบบนี้

    ทางแก้ ต้องใช้ฟังก์ชันกระตุ้นแบบ ไม่เป็นเส้นตรง (Non-linear) เพื่อดัดและแบ่งพื้นที่ข้อมูล ทำให้โครงข่ายหลายชั้นเรียนรู้รูปแบบโค้งหรือซับซ้อนได้

    สไลด์ 8

    ฟังก์ชันกระตุ้นมาตรฐาน: Step และ Sigmoid

    สองฟังก์ชันนี้เป็นยุคคลาสสิก

    Step Function (ขั้นบันได) ผลลัพธ์คือ 0 หรือ 1 ตัดสลับทันทีเมื่อ z ผ่านเกณฑ์ ตรงกับกฎ All-or-None ของเซลล์จริง ข้อจำกัดคือ หาความชันไม่ได้ (กราฟเป็นขั้นบันได ความชันเป็นศูนย์หรือไม่นิยาม) ทำให้ใช้ Gradient Descent ปรับน้ำหนักไม่ได้ โมเดลจึงเรียนรู้ต่อไม่ได้

    Sigmoid Function บีบผลลัพธ์ให้อยู่ในช่วง (0, 1) เป็นเส้นโค้งรูปตัว S จึงอ่านเป็นความน่าจะเป็นได้ และมีความชันทุกจุด ข้อจำกัดคือ ความชันหาย (Vanishing Gradient) เมื่อ z มีค่าสูงหรือต่ำมาก ปลายกราฟแบนเกือบราบ ความชันเกือบเป็นศูนย์ การปรับน้ำหนักจึงแทบไม่ขยับ โดยเฉพาะในโครงข่ายที่ลึก

    สไลด์ 9

    ฟังก์ชันกระตุ้นมาตรฐาน (ต่อ): ReLU และ Softmax

    เข้าใจง่าย ๆReLU = “ถ้าติดลบ ไม่สนใจ ถ้าบวก ส่งต่อตามจริง” · Softmax = แบ่งพิซซ่า 100% ให้แต่ละคำตอบตามความมั่นใจ

    สองฟังก์ชันนี้เป็นขุมพลังของ Deep Learning ยุคปัจจุบัน

    ReLU (Rectified Linear Unit) f(z) = max(0, z) ค่าลบกลายเป็น 0 ค่าบวกปล่อยผ่านตามเดิม จุดเด่นคือคำนวณเร็วมาก และไม่เกิดปัญหาความชันหายในฝั่งบวก (ความชันฝั่งบวกเป็น 1 เสมอ) จึงเป็นมาตรฐานของ Hidden Layer

    Softmax Function ใช้ใน Output Layer เพื่อแปลงคะแนนดิบของแต่ละคลาสเป็นสัดส่วนความน่าจะเป็นที่รวมกันได้ 100% เหมาะกับการแยกข้อมูลหลายกลุ่ม เช่น คะแนนดิบ [2, 1, 0.1] จะกลายเป็นประมาณ [0.66, 0.24, 0.10]

    สไลด์ 10

    โครงสร้างแบบหลายชั้น (Multilayer Perceptron: MLP)

    ทำไมต้องหลายชั้น โหนดเดี่ยวแก้ปัญหาซับซ้อนไม่ได้ (เช่น XOR) การร้อยเรียงโหนดหลายตัวหลายชั้นช่วยสร้าง การเรียนรู้เชิงลำดับชั้น (Hierarchical Learning) ชั้นแรก ๆ เรียนรู้ลักษณะง่าย ๆ ชั้นหลังนำมาประกอบเป็นลักษณะที่ซับซ้อนขึ้น

    MLP มีองค์ประกอบหลัก 3 ชั้น

    • ชั้นข้อมูลเข้า (Input Layer)
    • ชั้นซ่อน (Hidden Layers) มีได้หลายชั้น
    • ชั้นข้อมูลออก (Output Layer)
    สไลด์ 11

    ชั้นข้อมูลเข้า (Input Layer)

    หน้าที่ รับข้อมูลดิบจากโลกจริง ซึ่งเรียกว่า Features โหนดหนึ่งตัวต่อข้อมูลหนึ่งตัวแปร

    จุดเด่น ไม่มีการคำนวณคณิตศาสตร์ในชั้นนี้ ทำหน้าที่กระจายสัญญาณไปยังทุกโหนดในชั้นถัดไปเท่านั้น จึงไม่มี Bias

    ตัวอย่างบริบทการศึกษา โหนดที่ 1 คือเวลาสะสมที่เข้าเรียน (ชั่วโมง) และโหนดที่ 2 คือคะแนนสอบกลางภาค (%)

    สไลด์ 12

    ชั้นซ่อน (Hidden Layers) และการสกัดคุณลักษณะ

    เข้าใจง่าย ๆเหมือนสายการผลิต คนแรกเห็นแค่เส้น คนถัดไปประกอบเส้นเป็นรูปร่าง คนสุดท้ายบอกได้ว่าเป็นหน้าใคร

    หน้าที่ แปลงและสกัดความสัมพันธ์เชิงลึก (Feature Representation) จากข้อมูลเข้า เรียกว่า “ซ่อน” เพราะเราไม่ได้เห็นหรือกำหนดค่าของมันโดยตรง

    • ความลึก (Depth) คือจำนวนชั้นซ่อน ยิ่งลึก โมเดลยิ่งแก้ปัญหาที่ซับซ้อนได้ (ที่มาของคำว่า Deep Learning)
    • ความกว้าง (Width) คือจำนวนโหนดในแต่ละชั้น ยิ่งกว้าง ยิ่งจำแนกแพทเทิร์นได้หลากหลาย

    กลไก แปลงข้อมูลระดับต่ำไปสู่ระดับสูง เช่น ในงานภาพ ชั้นแรกจับเส้นขอบ ชั้นถัดไปรวมเส้นเป็นรูปร่าง ชั้นท้ายรวมรูปร่างเป็นใบหน้า

    สไลด์ 13

    ชั้นข้อมูลออก (Output Layer)

    หน้าที่ แสดงผลการทำนายตามโจทย์ที่กำหนด จำนวนโหนดและฟังก์ชันขึ้นกับชนิดของโจทย์

    • Binary Classification (สองคำตอบ เช่น ผ่าน/ไม่ผ่าน) ใช้ 1 โหนด กับฟังก์ชัน Sigmoid ได้ความน่าจะเป็นระหว่าง 0–1
    • Multi-class Classification (หลายคลาส) ใช้หลายโหนดเท่าจำนวนคลาส กับฟังก์ชัน Softmax ได้การแจกแจงความน่าจะเป็นของแต่ละคลาส
    • Regression (ตัวเลขต่อเนื่อง) ใช้ 1 โหนด กับฟังก์ชัน Linear (ไม่บีบค่า) ได้ตัวเลขออกมาตรง ๆ
    สไลด์ 14

    เส้นประสาทเทียมและการนับพารามิเตอร์

    เข้าใจง่าย ๆนับเส้นที่ลากระหว่างชั้น (ทุกจุดต่อทุกจุด) แล้วบวกจำนวนจุดที่ไม่ใช่ชั้นแรก

    สายเชื่อมต่อ (Weights) ในโครงข่ายแบบ Fully Connected โหนดทุกตัวลากเส้นเชื่อมไปยังทุกโหนดในชั้นถัดไป แต่ละเส้นมีน้ำหนักของตัวเอง 1 ค่า จำนวน Weights ระหว่างสองชั้นจึงเท่ากับ จำนวนโหนดชั้นก่อน × จำนวนโหนดชั้นถัดไป

    ค่าความเอนเอียง (Bias) โหนดในชั้นซ่อนและชั้นออกจะมี Bias ประจำตัวเสมอ ตัวละ 1 ค่า ส่วนชั้น Input ไม่มี

    Trainable Parameters คือจำนวนสิ่งที่ AI ต้องเรียนรู้ = (จำนวน Weights) + (จำนวน Biases)

    ลองคิด โครงข่าย 2–3–1 → Weights = 2×3 + 3×1 = 9, Biases = 3 + 1 = 4, รวม 13 · โครงข่าย 4–5–3 → Weights = 20 + 15 = 35, Biases = 5 + 3 = 8, รวม 43

    สไลด์ 15

    การเดินทางของข้อมูล (Forward Propagation)

    นิยาม กระบวนการคำนวณเชิงคณิตศาสตร์ทางเดียว (One-way Flow) จาก Input ไปสู่ Output

    บทบาท ใช้ในการทำนายผล (Inference / Prediction) ทุกครั้งที่โมเดลตอบคำถาม มันทำ Forward Propagation 1 รอบ

    แผนภาพ Input → Hidden 1 → Hidden 2 → Output ข้อมูลไหลไปข้างหน้าเท่านั้น ไม่มีการย้อนกลับในขั้นนี้

    สไลด์ 16

    สมการคณิตศาสตร์ที่ใช้ทายผล

    ในแต่ละชั้น l ของเครือข่าย คำนวณ 2 ขั้น

    • Step 1 · Weighted Sum z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ นำผลลัพธ์จากชั้นก่อน a⁽ˡ⁻¹⁾ มาคูณกับเมทริกซ์น้ำหนัก W ของชั้นนี้ แล้วบวก Bias
    • Step 2 · Activation a⁽ˡ⁾ = f⁽ˡ⁾(z⁽ˡ⁾) แปลงผลรวมผ่านฟังก์ชันกระตุ้น ได้ผลลัพธ์ของชั้นนี้ ซึ่งจะเป็นข้อมูลเข้าของชั้นถัดไป

    หมายเหตุ คอมพิวเตอร์ใช้ การคูณเมทริกซ์ (Matrix Multiplication) เพื่อคำนวณทุกโหนดในชั้นพร้อมกันรวดเดียว ไม่ต้องวนทีละโหนด ซึ่งเป็นเหตุผลที่การ์ดจอ (GPU) เร่งงานนี้ได้ดี

    สไลด์ 17

    สรุปภาพรวมโครงข่ายประสาทเทียม

    การยกระดับความรู้ในแต่ละชั้น (Hierarchical Transformation) ข้อมูลดิบ → สกัดคุณลักษณะย่อย → รวมเป็นรูปทรงนามธรรม → คำตอบสุดท้าย

    ข้อสรุป Forward Propagation คือกระบวนการจัดระเบียบพื้นที่ข้อมูล แต่ละชั้นบิดและแปลงข้อมูล เพื่อให้ปัญหาที่เคยซับซ้อน (เช่น แบ่งด้วยเส้นตรงไม่ได้) ถูกคลี่ออกจนขีดเส้นแบ่งกลุ่มได้ง่าย ๆ ในชั้นท้าย

    สไลด์ 18

    โครงข่ายประสาทเทียมรู้ได้อย่างไรว่าตัวเองทายผิด

    เข้าใจง่าย ๆLoss คือคะแนนความผิด ยิ่งต่ำยิ่งดี การ Train คือพยายามทำให้คะแนนนี้ใกล้ศูนย์

    Loss Function คือมาตรวัดที่เป็นตัวเลขเชิงปริมาณ สะท้อนว่าโครงข่ายทายผิดมากแค่ไหน (ถ้าเฉลี่ยทั้งชุดข้อมูลมักเรียกว่า Cost Function)

    สมการตรรกะพื้นฐาน Error = f(ŷ, y)

    • ŷ (อ่านว่า y-hat) คือคำตอบที่ AI เดา
    • y คือคำตอบจริง (เฉลย)

    เป้าหมายสูงสุดของการ Train คือปรับค่าน้ำหนัก (Weights) เพื่อทำให้ค่า Loss ลดลงจนเข้าใกล้ 0 ให้ได้มากที่สุด

    สไลด์ 19

    การเลือกมาตรวัดให้ตรงกับประเภทงาน

    ปัญหาพยากรณ์ค่าต่อเนื่อง (Regression) ใช้ Mean Squared Error (MSE)

    MSE = (1/N) Σ (y − ŷ)²

    หาผลต่างระหว่างเฉลยกับคำทายแต่ละข้อ ยกกำลังสอง แล้วหาค่าเฉลี่ย จุดเด่นคือการยกกำลังสอง ลงโทษหนักหากทายผิดไปจากเฉลยมาก ๆ ผิด 1 หน่วยได้ 1 แต่ผิด 3 หน่วยได้ 9 ตัวอย่าง y = [3, 5], ŷ = [2, 7] → (1 + 4)/2 = 2.5

    ปัญหาจำแนกประเภท (Classification) ใช้ Cross-Entropy (Log Loss)

    Loss = −[ y·log(ŷ) + (1 − y)·log(1 − ŷ) ]

    ใช้ลอการิทึมลงโทษโมเดลอย่างรุนแรง หากโมเดลทายผิดแต่มั่นใจมาก เช่น เฉลยคือ 1 แต่โมเดลให้ความน่าจะเป็น 0.01 ค่า log(0.01) ติดลบมาก Loss จึงสูงมาก

    สไลด์ 20

    กฎการปรับน้ำหนัก (The Math of Learning)

    เข้าใจง่าย ๆเหมือนเดินลงเขาตอนหมอกหนา มองไม่เห็นข้างล่าง แต่รู้ว่าพื้นใต้เท้าลาดไปทางไหน ก็ก้าวไปทางที่ลาดลง

    สมการรากฐานการอัปเดตค่าน้ำหนัก (Weight Update Rule)

    w_new = w_old − α · ∂J/∂w
    • w_new ค่าน้ำหนักใหม่ที่ฉลาดขึ้น
    • w_old ค่าน้ำหนักเดิม
    • ∂J/∂w ความชันของ Loss เทียบกับน้ำหนัก บอกทิศทางของข้อผิดพลาด ถ้าเพิ่ม w แล้ว Loss เพิ่ม ความชันเป็นบวก
    • α (Alpha) อัตราการเรียนรู้ (Learning Rate) หรือความกว้างของการก้าวเดิน

    เครื่องหมาย ลบ สำคัญ: เราต้องเดิน สวนทางความชัน เพื่อลงไปหาจุดที่ Loss ต่ำสุด เหมือนเดินลงหุบเขา วิธีนี้เรียกว่า Gradient Descent

    ลองคิด w_old = 0.8, α = 0.1, ∂J/∂w = 2 → w_new = 0.8 − 0.2 = 0.6

    สไลด์ 21

    อัตราการเรียนรู้ (Learning Rate · α)

    เข้าใจง่าย ๆก้าวสั้นไปถึงช้า ก้าวยาวไปกระโดดข้ามหุบ ก้าวพอดีถึงจุดต่ำสุดเร็วและนิ่ง

    • α เล็กเกินไป (เช่น 0.0001) ก้าวสั้นมาก โมเดลเรียนรู้ช้าสุด ๆ (Slow Convergence) ต้องใช้รอบจำนวนมาก
    • α เหมาะสม (เช่น 0.01) ก้าวอย่างมีเสถียรภาพ ลู่เข้าสู่จุดต่ำสุดได้อย่างราบรื่น
    • α ใหญ่เกินไป (เช่น 0.9) ก้าวกระโดดกว้างเกิน กระดอนข้ามหุบเขาไปมา (Overshooting) ค่า Loss อาจพุ่งทะลุจอแทนที่จะลดลง
    สไลด์ 22

    การย้อนกลับด้วยคณิตศาสตร์ (Backpropagation)

    เข้าใจง่าย ๆเหมือนสอบสวนย้อนหลังว่าใครทำให้ผลผิด ไล่จากปลายทางกลับมาทีละด่าน แล้วแบ่งความรับผิดชอบให้แต่ละเส้น

    ปัญหาคือ เรารู้ว่าคำตอบสุดท้ายผิดเท่าไร แต่โครงข่ายมีน้ำหนักเป็นร้อยเป็นพันเส้น จะรู้ได้อย่างไรว่าแต่ละเส้นรับผิดชอบความผิดนั้นแค่ไหน คำตอบคือ กฎลูกโซ่แห่งแคลคูลัส (The Chain Rule) Backprop หาอนุพันธ์ย่อยย้อนกลับทีละชั้น จาก Output ไปหา Input

    ∂Loss/∂wᵢⱼ = ∂Loss/∂Output × ∂Output/∂Hidden × ∂Hidden/∂wᵢⱼ

    อ่านว่า ความชันของ Loss เทียบกับน้ำหนักเส้นหนึ่ง เท่ากับผลคูณของความชันแต่ละช่วงที่สัญญาณเดินผ่าน เมื่อได้ค่านี้แล้วก็นำไปใส่สูตรปรับน้ำหนักในสไลด์ 20

    สไลด์ 23

    สรุปวงจรการเรียนรู้ 1 รอบเต็ม

    เข้าใจง่าย ๆทาย → ตรวจ → หาสาเหตุ → แก้ วนไปเรื่อย ๆ เหมือนนักเรียนทำแบบฝึกหัดซ้ำจนเก่ง

    วงจรการฝึกฝน 1 Epoch (The Training Loop) มี 4 ขั้นตอนเรียงกัน

    1. Forward Pass เดาคำตอบไปข้างหน้า
    2. Calculate Loss ตรวจข้อสอบและวัดความผิดพลาด
    3. Backpropagation สืบสวนหาสาเหตุย้อนหลังว่าน้ำหนักเส้นไหนทำให้ผิด
    4. Update Weights ปรับค่าน้ำหนักด้วย Gradient Descent

    ครบ 4 ขั้นเรียกว่า 1 Epoch โมเดลจะทำซ้ำกระบวนการนี้นับพันครั้ง จน Loss ลดลงจนพอใจ
