กระบวนทัศน์การเรียนรู้ของเครื่อง

ทั้งบทนี้มีเรื่องเดียวที่ต้องจำ: เดิม คนเขียนกฎ f เอง แต่ Machine Learning คือ ให้เครื่องหา f เองจากข้อมูล ที่เหลือเป็นแค่ว่าข้อมูลที่ให้เครื่องเรียนมีเฉลยหรือไม่ และมีรางวัลหรือไม่

1 · Paradigm Shift สไลด์ 2–4

จาก “คนเขียนกฎ” สู่ “เครื่องหากฎ”

มองทุกโปรแกรมเป็นสมการ f(x) = y โดย x คือสิ่งที่ป้อนเข้า y คือคำตอบ และ f คือกฎที่แปลง x เป็น y สองยุคต่างกันที่ว่า ใครเป็นคนสร้าง f

ทำไม Rule-based ถึงไปไม่รอด

  • Rule Explosion (กฎระเบิด) ยิ่งปัญหาซับซ้อน กฎยิ่งทับซ้อนกันจนดูแลไม่ไหว
  • Endless Edge Cases (ข้อยกเว้นไม่รู้จบ) คนคิดเงื่อนไขในโลกจริงได้ไม่ครบ

งานที่ Rule-based ทำได้แย่

  • คัดกรองอีเมลสแปม
  • จดจำลายมือเขียน
  • ประเมินพฤติกรรมมนุษย์
ตัวอย่างRule-based (พังตรงไหน)Data-driven (แก้ยังไง)
อีเมลสแปมเจอคำว่า “ฟรี” ให้ถือเป็นสแปม แต่ถ้าพิมพ์ “ฟ.รี” ก็หลุดNaive Bayes คำนวณความน่าจะเป็นจากกลุ่มคำ
เด็กเสี่ยง Dropoutขาดเรียน > 3 ครั้ง AND ควิซ < 50% ซึ่งแข็งทื่อเกินไปลากเส้น Decision Boundary ในข้อมูลพฤติกรรมหลายมิติ
ลายมือเลข 8ต้องมีวงกลมซ้อน 2 วง แต่ถ้าเขียนเบี้ยว ระบบก็พังอ่านความสว่าง 784 พิกเซล (28×28) แล้วปรับ Weights
2 · 3 ML Paradigms สไลด์ 5, 22

แผนที่ 3 กระบวนทัศน์

ถามตัวเองแค่ 2 ข้อ แล้วจะรู้ทันทีว่าโจทย์เป็นแบบไหน

Supervised · มีผู้สอน

มี x และมีเฉลย y

เหมือนทำแบบฝึกหัดที่มีเฉลยท้ายเล่ม

Unsupervised · ไม่มีผู้สอน

มีแค่ x ไม่มีเฉลย

เหมือนเด็กจัดกล่องเลโก้ที่ไม่มีคู่มือ

Reinforcement · เสริมแรง

ลองผิดลองถูก (Trial & Error) แล้วได้ Reward

เหมือนฝึกสุนัข หรือเล่นเกม

3 · Supervised Learning สไลด์ 6–8 · ใบงานการทดลองที่ 1

เรียนจากตัวอย่างที่มีเฉลย

ป้อนข้อมูลเป็นคู่ (xi, yi) ให้โมเดลหาฟังก์ชัน f ที่ทำให้ f(x) = y งานหลักมี 2 แบบ ต่างกันที่ หน้าตาของเฉลย

ตัวอย่างอื่นในสไลด์ 7 Regression หลายตัวแปร ราคาบ้าน: x = [พื้นที่, ห้องนอน, ระยะรถไฟฟ้า, อายุบ้าน] โมเดลสร้างสมการเป็น Hyperplane · High-dimensional Classification: ภาพเซลล์มะเร็งเต้านมใช้ 30 ตัวแปร

หัวใจของการเรียน: ทาย, หา Error, ปรับ Weight

ทุกโมเดลแบบมีผู้สอนวนทำ 3 ขั้นนี้ซ้ำ โดย 1 รอบ (เห็นข้อมูลครบทั้งชุด) เรียกว่า epoch

ลองเป็นครูสอน AI เอง (ใบงานข้อ 1.2.3)

อ่าน 3 ชั่วโมง (x = 3) ได้ 15 คะแนน (target = 15) AI เริ่มที่ w = 2 กด “สอน 1 รอบ” แล้วดู Error ลดลง

จำให้ขึ้นใจ • ทายต่ำกว่าเฉลย → error เป็นบวก → เพิ่ม w · ทายสูงกว่าเฉลย → error เป็นลบ → ลด w • learning rate คือขนาดก้าว ถ้าเล็กไปจะเรียนช้า ถ้าใหญ่ไปจะเลยเป้าแกว่งไปมา (ลองเลือก 0.8) • สไลด์ 8 เขียนกลับเครื่องหมาย error = pred − y และ w = w − lr·error·x ความหมายเหมือนกัน (ตัวคูณ x มาจาก gradient)
ดูโค้ดสไลด์ 8 
data = [(1, 20), (2, 40), (3, 60), (4, 80), (5, 100)]
w = 0.0 ; learning_rate = 0.01

for epoch in range(100):
  for x, y_true in data:
      y_pred = w * x                         # 1. ทาย
      error = y_pred - y_true                # 2. หา Error
      w = w - (learning_rate * error * x)    # 3. ปรับ Weight

# ผลลัพธ์: w เข้าใกล้ 20.0 (สูตร y = 20 * x)
4 · Unsupervised Learning สไลด์ 9–11 · ใบงานการทดลองที่ 2

ค้นหาโครงสร้างที่ซ่อนอยู่ โดยไม่มีเฉลย

ป้อนแค่ข้อมูลดิบ x แล้วให้ระบบหารูปแบบเอง ไม่มีใครบอกว่าใครอยู่กลุ่มไหน ระบบดูเองว่า อะไรอยู่ใกล้อะไร

K-Means ทำงานยังไง (1 รอบ)

สูตร Euclidean Distance (2 มิติ) ที่โจทย์ชอบให้คิด d = √((x₁−x₂)² + (y₁−y₂)²) ตัวอย่าง: นักเรียน [2,1] ห่างจาก A [1,1] = √(1+0) = 1 และห่างจาก B [9,9] = √(49+64) ≈ 10.63 จึงเข้ากลุ่ม A

Customer Segmentation

x = [รายได้, คะแนนใช้จ่าย] แล้วใช้ K-Means แบ่งกลุ่มลูกค้า

Association Rules

Walmart พบว่า ผ้าอ้อม มักถูกซื้อคู่กับ เบียร์ · ใบงาน: คนยืม “คณิต” ยืม “ฟิสิกส์” คู่กันบ่อยสุด (3 ครั้ง) จึงควรแนะนำฟิสิกส์

Outlier Detection

ใบงาน 2.2.4: มาสาย [1,0,2,1,0,15,1,2] ค่าเฉลี่ย 2.75 คนที่ 6 ห่าง 12.25 > 5 จึงผิดปกติ

5 · Reinforcement Learning สไลด์ 12–17 · ใบงานการทดลองที่ 3

ลองผิดลองถูก แล้วเก็บรางวัลให้ได้มากที่สุด

Agent อยู่ใน Environment และเลือก Action เพื่อให้ได้ รางวัลสะสมรวมสูงสุด (Maximize Cumulative Reward) ซึ่งไม่ใช่แค่รางวัลของตาเดียว

องค์ประกอบหน้าที่ในเกมในห้องเรียน (Adaptive Learning)
Agentดู State แล้วเลือก Action เพื่อเป้าหมายระยะยาวตัวละครระบบ AI แนะนำบทเรียน
Environmentตอบสนอง Action ส่ง State ใหม่และ Reward กลับมาด่านในเกมนักเรียน (คนจริงหรือแบบจำลอง)
Actionสิ่งที่ Agent เลือกทำได้ ณ เวลานั้นเดิน / กระโดดส่งโจทย์ยากหรือง่าย
Stateข้อมูลปัจจุบันที่ใช้ตัดสินใจพิกัด, พลังชีวิตระดับความรู้, คะแนนล่าสุด
Rewardแต้มบวก (รางวัล) หรือลบ (บทลงโทษ) ทันทีหลังทำคะแนนเกมทำโจทย์ผ่าน +, กดออกเพราะยากไป −

ตัวอย่างที่ต้องจำ

  • ฝึกสุนัข นั่งได้ขนม +1 · เห่าโดนดุ −1
  • CartPole ขยับรถซ้าย-ขวาให้ไม้ไม่ล้ม (หลักของโดรนและหุ่นยนต์ทรงตัว)
  • Super Mario ยอมเสี่ยงเหยียบศัตรูเพื่อคะแนนที่สูงกว่า (วางแผนระยะยาว)
  • AlphaGo Self-play นับล้านกระดาน ค้นพบกลยุทธ์ “สละหมาก” เพื่อยึดพื้นที่ระยะยาว
  • Adaptive Learning Pathway AI จัดข้อสอบตามความเข้าใจ เพื่อให้เด็กสอบผ่านปลายภาคสูงสุด
6 · Generalization สไลด์ 18–20

Overfitting กับ Underfitting

เป้าหมายของ ML ไม่ใช่ ทำข้อสอบเก่า (Training Data) ได้ 100% แต่คือ Generalization หมายถึงทำข้อสอบใหม่ที่ไม่เคยเห็น (Unseen Data) ได้ดี

Underfitting · “ขี้เกียจ”Overfitting · “นักท่องจำ”
นิยามโมเดลง่ายเกินไป จับความสัมพันธ์อะไรไม่ได้โมเดลซับซ้อนเกินไป ท่องจำไปถึง Noise
ข้อสอบซ้อม / จริงตกทั้งคู่ซ้อมได้เต็ม · สอบจริงพัง
นักเรียนไม่อ่าน ตอบ ก. ทุกข้อท่องโจทย์เก่า แต่ย้ายข้างสมการไม่เป็น
จำรูปสุนัขมี 4 ขาคือสุนัข จึงทายแมว ม้า โต๊ะ เป็นสุนัขต้องเป็นชิบะสีน้ำตาลใส่ปลอกคอแดง พอเจอพุดเดิ้ลขาวก็ทายว่าไม่ใช่สุนัข
ราคาบ้านเส้นแนวนอน ทุกขนาดราคาเท่ากันเส้นคดเคี้ยวไล่ทุกจุด รวมถึง “บ้านผีสิง”
วิธีแก้เพิ่มความซับซ้อนโมเดล · เพิ่ม Featuresเพิ่มข้อมูล · ตัด Noise · ลดความซับซ้อน (Regularization)
จำคู่ Bias / Variance Under = High Bias (ลำเอียงไปทางง่ายเกิน) · Over = High Variance (แกว่งตามข้อมูลทุกจุด) ข้อสอบชอบสลับคู่นี้มาหลอก
7 · จริยธรรมและจิตวิทยาการศึกษา สไลด์ 21

ครูต้องอยู่ในวงจรเสมอ (Human-in-the-Loop)

AI คือเครื่องคำนวณสถิติ

AI ไม่มีสามัญสำนึก ถ้าข้อมูลในอดีตมีอคติ โมเดลก็จะเรียนอคตินั้นไปด้วย (Algorithmic Bias)

Self-fulfilling Prophecy

การทำนายที่ทำให้ตัวเองเป็นจริง ถ้า AI บอกว่าเด็กคนนี้ “เสี่ยงตก” แล้วครูเลิกให้โอกาส เด็กก็จะตกจริง ห้ามใช้ผลของ AI ตราหน้าเด็ก

ครูเป็นผู้ถือความเห็นอกเห็นใจ (Empathy) และ เป็นผู้ตัดสินใจขั้นสุดท้าย
