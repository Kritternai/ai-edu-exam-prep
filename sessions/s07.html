3 · Activation Function สไลด์ 7–9

  
ทำไมต้องมีฟังก์ชันกระตุ้น

  

    

      
ปัญหาของสมการเส้นตรง

ปัญหา XOR

      
ข้อมูลจริงแบ่งด้วยเส้นตรงเส้นเดียวไม่ได้ (Non-linearly Separable) จึงต้องใช้ฟังก์ชัน ไม่เป็นเส้นตรง (Non-linear)

    

  


  

  

  

    
ฟังก์ชันผลลัพธ์จุดเด่น / ข้อจำกัดใช้ที่ไหน

4 · Multilayer Perceptron สไลด์ 10–17

  
ต่อกันหลายชั้น เพื่อเรียนรู้เป็นลำดับขั้น

  
โหนดเดี่ยวแก้ปัญหาซับซ้อนไม่ได้ การร้อยหลายโหนดหลายชั้นทำให้เกิด Hierarchical Learning ข้อมูลดิบ → ลักษณะย่อย → รูปทรงนามธรรม → คำตอบ


  

  

    

      
Input Layer

      
รับข้อมูลดิบ (Features) ไม่มีการคำนวณ แค่กระจายสัญญาณ

    

    

      
Hidden Layers

      
สกัดความสัมพันธ์เชิงลึก (Feature Representation) · Depth = จำนวนชั้น ยิ่งลึกยิ่งแก้ปัญหาซับซ้อน · Width = จำนวนโหนดต่อชั้น ยิ่งกว้างยิ่งจับแพทเทิร์นหลากหลาย

    

    

      
Output Layer

      
แสดงผลทำนายตามโจทย์ (ดูตารางด้านล่าง)

    

  


  

  

    
ประเภทโจทย์จำนวนโหนด OutputActivationผลลัพธ์

    
      
Binary Classification1Sigmoidความน่าจะเป็น 0–1

      
Multi-class Classificationหลายโหนด (เท่าจำนวนคลาส)Softmaxการแจกแจงความน่าจะเป็นของแต่ละคลาส

      
Regression1Linearตัวเลขต่อเนื่อง

    
  

  


  
นับพารามิเตอร์ (โจทย์ชอบออก)

  

    Trainable Parameters = จำนวน Weights + จำนวน Biases
    • Weights ระหว่าง 2 ชั้น = โหนดชั้นก่อน × โหนดชั้นถัดไป
    • Bias มีเฉพาะโหนดใน Hidden และ Output (Input ไม่มี)
    ตัวอย่างภาพบน 2–3–1: Weights = 2×3 + 3×1 = 9 · Biases = 3 + 1 = 4 · รวม 13
    ลองเอง 4–5–3: Weights = 20 + 15 = 35 · Biases = 5 + 3 = 8 · รวม 43
  


  
Forward Propagation · การทายผล

  
ข้อมูลไหล ทางเดียว (One-way Flow) จาก Input → Hidden 1 → Hidden 2 → Output ใช้ตอนทำนาย (Inference) ในแต่ละชั้นทำ 2 ขั้น

  

    
Step 1 · Weighted Sum
z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾

    
Step 2 · Activation
a⁽ˡ⁾ = f⁽ˡ⁾(z⁽ˡ⁾)

  

  
คอมพิวเตอร์ใช้ การคูณเมทริกซ์ คำนวณทั้งชั้นรวดเดียว Forward Propagation คือการจัดระเบียบพื้นที่ข้อมูล จนปัญหาที่ซับซ้อนถูกคลี่ออกและขีดเส้นแบ่งได้ง่ายในชั้นท้าย







  
5 · Loss Function สไลด์ 18–19

  
รู้ได้อย่างไรว่าทายผิด

  
Loss Function คือตัวเลขที่บอกว่าผิดมากแค่ไหน Error = f(ŷ, y) โดย ŷ (y-hat) คือที่ AI เดา และ y คือเฉลย เป้าหมายของการ Train คือ ปรับ Weights ให้ Loss ลดลงเข้าใกล้ 0

  

    

      
MSE · Mean Squared Error

      
ใช้กับ Regression

      
MSE = (1/N) Σ (y − ŷ)²

      
ยกกำลังสองเพื่อ ลงโทษหนักเมื่อทายห่างมาก

      
ตัวอย่าง: y = [3, 5], ŷ = [2, 7] → (1² + 2²) / 2 = 2.5

    

    

      
Cross-Entropy · Log Loss

      
ใช้กับ Classification

      
−[y log ŷ + (1−y) log(1−ŷ)]

      
ใช้ลอการิทึม ลงโทษรุนแรงเมื่อทายผิดแต่มั่นใจมาก

    

  







  
6 · Learning สไลด์ 20–23

  
ปรับน้ำหนักด้วย Gradient Descent

  

    Weight Update Rule
    w_new = w_old − α · ∂J/∂w
    ∂J/∂w = ความชัน (ทิศทางของข้อผิดพลาด) · α = Learning Rate (ความกว้างของก้าว) · ลบเพราะต้องเดิน สวนทางความชัน ลงหุบเขา
    ตัวอย่าง: w_old = 0.8, α = 0.1, ∂J/∂w = 2 → w_new = 0.8 − 0.2 = 0.6
  


  

  
Backpropagation · ย้อนหาว่าใครผิด

  
ใช้ Chain Rule ของแคลคูลัส หาอนุพันธ์ย่อยย้อนกลับทีละชั้น จาก Output กลับไปหา weight แต่ละเส้น

  
∂Loss/∂wᵢⱼ = ∂Loss/∂Output × ∂Output/∂Hidden × ∂Hidden/∂wᵢⱼ


  
วงจรการฝึก 1 Epoch
