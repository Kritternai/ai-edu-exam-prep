# ติวสอบ AI เพื่อการศึกษา

เว็บสรุปบทเรียนพร้อมภาพประกอบ และโหมดทำข้อสอบปรนัย วิชาปัญญาประดิษฐ์เพื่องานด้านการศึกษา

เป็นเว็บ static ล้วน ไม่ต้อง build ใช้ GitHub Pages จาก branch `main` ได้เลย

## โครงสร้าง

```
index.html            หน้าแรก แสดงรายการ session จาก data/sessions.json
exam.html             โหมดทำข้อสอบ
sessions/sNN.html     สรุปของแต่ละ session
data/sessions.json    รายการ session (ลำดับ ชื่อ ลิงก์สรุป ลิงก์คลังข้อสอบ)
data/quiz/sNN.json    คลังข้อสอบของแต่ละ session
assets/style.css      สไตล์ร่วมทุกหน้า (รองรับโหมดมืด)
assets/site.js        ตัวช่วยโหลดข้อมูลและเก็บคะแนนดีสุด
assets/exam.js        ตรรกะโหมดทำข้อสอบ
```

## โหมดทำข้อสอบ

- เลือกได้หลาย session จำนวนข้อ 10, 20 หรือทั้งหมด
- **ฝึกทำ** ตอบแล้วเห็นเฉลยและคำอธิบายทันที
- **สอบจริง** แก้คำตอบได้จนกว่าจะส่ง แล้วเห็นเฉลยทั้งหมดตอนจบ
- สุ่มลำดับข้อและตัวเลือกทุกครั้ง ทำเฉพาะข้อที่ผิดซ้ำได้
- คะแนนดีสุดเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น
- ลิงก์ตรงไปยัง session ได้ด้วย `exam.html?s=06` หรือหลาย session `exam.html?s=06,07`
- คีย์ลัด: `1`–`4` เลือกคำตอบ, `←` `→` เปลี่ยนข้อ

## เพิ่ม session ใหม่

1. สร้าง `sessions/sNN.html` โดยคัดลอกโครง `sessions/s06.html` (topbar, `.page`, `section.note`)
2. สร้าง `data/quiz/sNN.json` รูปแบบเดียวกับ `data/quiz/s06.json`

   ```json
   {
     "session": "07",
     "questions": [
       {
         "id": "s07-01",
         "q": "คำถาม",
         "choices": ["ตัวเลือกที่ถูก", "ตัวลวง 1", "ตัวลวง 2", "ตัวลวง 3"],
         "answer": 0,
         "explain": "เหตุผลของเฉลย",
         "ref": "สไลด์ 5"
       }
     ]
   }
   ```

   `answer` คือ index ของตัวเลือกที่ถูกก่อนสุ่ม ตัวเลือกถูกสุ่มลำดับเสมอ จึงห้ามใช้ตัวเลือกแบบ “ถูกทุกข้อ” หรือ “ข้อ ก และ ข”
3. ใส่ `"page"` และ `"quiz"` ของ session นั้นใน `data/sessions.json` หน้าแรกและหน้าข้อสอบจะเห็นเอง

## รันในเครื่อง

หน้าเว็บโหลด JSON ด้วย `fetch` จึงต้องเปิดผ่าน web server ไม่ใช่ดับเบิลคลิกไฟล์

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

ไฟล์สไลด์ PDF ต้นฉบับไม่อยู่ใน repo นี้
